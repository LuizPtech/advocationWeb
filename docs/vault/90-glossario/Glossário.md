# Glossário

## Termos jurídicos usados na plataforma

- **Ad judicia** — poderes gerais para representar em juízo. Usado na [[Playbook - Gerar documentos|Procuração]].
- **Cliente** — no schema é `user` com `role = 'CLIENT'`.
- **Contratante / Contratado** — partes num contrato de honorários.
- **Guarda compartilhada** — modelo em que ambos os pais têm decisões conjuntas.
- **Inventário extrajudicial** — feito em cartório, sem processo, quando há acordo.
- **Lead** — pessoa que preencheu o formulário de contato mas ainda não virou cliente.
- **OAB** — Ordem dos Advogados do Brasil + número de inscrição.
- **Partilha** — divisão de bens (divórcio ou inventário).
- **Pensão alimentícia** — valor pago para sustento (filhos, ex-cônjuge).
- **Rescisão** — término de contrato de trabalho e cálculo das verbas.

## Termos técnicos

- **ADR** — Architecture Decision Record. Registra por que uma escolha foi feita.
- **App Router** — sistema de rotas do Next.js baseado em pastas em `src/app/`.
- **cuid2** — gerador de ID único e ordenável cronologicamente.
- **JWT** — JSON Web Token; formato usado pela sessão do Auth.js.
- **MOC** — Map of Content. Nota-índice no Obsidian (esta [[00 - Início]] é uma MOC).
- **RLS** — Row Level Security. Regras de acesso no Postgres/Supabase.
- **Server Action** — função assíncrona chamada direto de forms no Next.js (`"use server"`).
- **Slug** — versão URL-friendly de um título (`Divórcio consensual` → `divorcio-consensual`).
- **Storage** — armazenamento de arquivos privado no Supabase.
- **Turbopack** — bundler moderno do Next.js (substituto do Webpack).

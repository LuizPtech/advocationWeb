# Vault Obsidian — Laura Eva Advocacia

Base de conhecimento e roadmap da plataforma, escrita em Markdown para o [Obsidian](https://obsidian.md).

## Como usar

1. Instale o Obsidian
2. Abra esta pasta (`docs/vault/`) como **Vault**
3. Comece por [[00 - Início]]

Todos os links entre notas usam a sintaxe `[[nome-da-nota]]`, então o grafo do Obsidian é populado automaticamente.

## Estrutura

- `00-inicio/` — porta de entrada, atalhos
- `10-produto/` — o que a plataforma faz
- `20-arquitetura/` — stack, dados, deploy
- `30-operacao/` — playbooks (como fazer X)
- `40-roadmap/` — próximas entregas, backlog
- `50-decisoes/` — ADRs (por que fizemos assim)
- `90-glossario/` — termos jurídicos e técnicos
